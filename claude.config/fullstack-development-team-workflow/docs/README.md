A workflow for a fullstack development team using Next.js, React, TypeScript, Tailwind CSS, Supabase, and ESLint with a code reviewer included.

## 🔍 How It Works

This is a **multi-agent workflow system**. When you run the command:

1. Claude Code reads the workflow instructions
2. Uses **Task tool** to call specialist agents
3. Each agent works on their part (architecture, database, frontend, etc.)
4. Results are coordinated and validated
5. Final output is integrated

**Important:** The main Claude Code instance acts as an **orchestrator**, not a developer. It delegates work to specialist agents.

## 📋 Workflow Phases

1. **Orchestrator** - Coordinates the fullstack development workflow
2. **Requirements Analyzer** - Analyzes the project requirements
3. **Frontend Implementer** - Implements the frontend using Next.js and React
4. **Backend Implementer** - Implements the backend using Supabase
5. **Code Reviewer** - Reviews code and makes approval decisions
6. **Quality Validator** - Validates code quality and adherence to standards

## ⚠️ Troubleshooting

### Claude Code is writing code directly instead of using agents

**Problem:** The workflow is being ignored.

**Solution:**
1. Make sure `.claude/CLAUDE.md` exists
2. Restart Claude Code
3. Try the command again with explicit instruction:
   ```
   /fullstack-development-team-workflow <task> (Important: Use Task tool to call agents)
   ```

### Agents are not being called

**Problem:** Task tool is not being invoked.

**Solution:**
- Check that `.claude/CLAUDE.md` contains the workflow instructions
- Make sure you're in a Claude Code session (not regular Claude)
- Try breaking it into steps: "Read /fullstack-development-team-workflow and tell me Phase 1"
